# 影之刃零自用自制 Mod

一些自己做来玩的《影之刃零》Mod，附带管理器。当前适配 Windows Steam 版 Build 26367565。

## 已更新

- **自动奔跑**：移动时自动奔跑，可通过快捷键开关。
- **地图**：扩展地图、分层地图和小地图，支持物品筛选及铃铛标记。
- **符类不消耗**：使用穿行符、兵刃逆炼符和影之消退符时不消耗。
- **短按确认、一键购买**：购买和升级免长按，可批量购买或升级当前分类。

自动奔跑、地图和符类不消耗已在游戏内验证；分层地图的铃铛标记和短按确认、一键购买尚待实机验证。

[下载管理器安装包](https://github.com/gantrol/phantom-blade-zero-mod-manager/releases/latest)，退出游戏后在管理器中启用需要的 Mod。缺少 .NET 运行时时，安装程序会联网下载并安装。

## 旧版阵亡名单

游戏更新后以下内容暂未适配当前版本：

- 演武场（历战）、角色旁杀气条、装备强化同步
- 一些后悔药：湖畔宝箱传送、记忆之花补救、宝鼎补遗 · 横刀后悔、宋小武补遗、陆三迁遗书补全
- 支线与存档管理工具

剧情快速跳过，此前因影响部分战斗末尾QTE重试，已停用。

目前没有朋友有这些需求，接下来也要忙别的，暂时没有更新计划。
