头顶杀气与紧张度 / Overhead killing intent and tension

主角头顶显示无文字双浅弧：上方朱红紧张度条更短、更细，下方为金色杀气条。
杀气直接读取 Shachi / Shachi_Max；紧张度读取游戏当前默认活跃会话的 FTensionReadout.Raw。
紧张度范围为 -100～100，依次对应空槽～满槽；0 为半槽。系统停用、无活跃会话或 Confidence 为 0 时隐藏朱红条。
双弧仅在主角具有 CharacterState.InCombat 标记时显示，脱战即隐藏，重新入战时刷新数值。
随 head 骨骼逐帧投影，缺少头部骨骼时回退至胶囊顶端；离屏、死亡、过场、暂停或 HUD 隐藏时隐藏。
不再添加敌人旁杀气条，保留游戏原生 HUD。仅显示，不修改属性、紧张度会话或战斗逻辑。
游戏关闭后，通过 Mod 管理器安装、启用、停用或卸载。版本 0.2.0，适配 Steam build 26367565；尚未进行游戏内验证。
使用 nativeRuntime 共享加载器，在 MainStart 完成后挂接原生 HUD，不覆盖游戏脚本。
升级时保留原启停状态并归档旧覆盖包；不能再用旧 Paks 三件套安装。
位置、尺寸与颜色配置：puerts/Config.js；修改后通过管理器 build killingIntent 重新构建。

Two unlabeled shallow arcs follow the player's head: a shorter, thinner vermilion tension arc above the gold killing-intent arc.
Killing intent reads Shachi / Shachi_Max. Tension reads FTensionReadout.Raw from the game's default active encounter.
Tension maps -100..100 to empty..full; 0 is half full. The red arc hides when the system is disabled, no session is active, or Confidence is zero.
The arcs show only while the player has CharacterState.InCombat, hide on leaving combat, and refresh values on re-entry.
The head bone is projected each frame, falling back to the capsule top. Meters also hide offscreen, on death, during cinematics/pause, and with the HUD.
No extra meters are added beside enemies. The game's original HUD remains. Display only: no attributes, tension sessions, or combat rules are modified.
Install, enable, disable or uninstall through the Mod Manager while the game is closed.
Version 0.2.0 targets Steam build 26367565; gameplay is not yet verified.
The shared nativeRuntime loader attaches to the original HUD after MainStart without replacing game scripts.
Migration preserves enablement and archives the old overrides. Do not install the legacy PAK triplet.
Edit puerts/Config.js for placement, size and color, then rebuild with the manager's build killingIntent command.
