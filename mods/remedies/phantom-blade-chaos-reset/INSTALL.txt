三面混沌重置 0.1.0

适配 Steam build 26266538。
将失败的“三面混沌”恢复到血色森林交战前。保留前置解谜、收集、其他任务、装备和角色进度。
按下快捷键后创建一个新的手动存档，原存档继续保留。

安装
退出游戏后，在解压后的目录运行 install.cmd。
安装前自动备份各账号的 PBZSaveGame.sav；该文件包含全部存档槽。
需要 Node.js。可用 node install.mjs --game "游戏目录" 指定安装路径。

使用
1. 启动游戏，从标题画面进入“读取存档”。
2. 选中要修复的存档，按 F9。
3. 出现“三面混沌已重置”后，确认读取自动选中的新手动存档。
4. 前往血色森林的原战斗地点。

支持前置任务已完成、血色森林遭遇战已失败、尚未完成第三阶段的普通存档。
读取界面会显示失败原因。手动存档满 20 个时，先用游戏自带功能腾出一个位置。
角色不会自动传送；获得的物品、击杀统计与成就记录保持原样。

卸载
退出游戏后运行 uninstall.cmd。已创建的重置存档会保留；可直接读取原存档回退。
安装与更新记录位于游戏 platform/steam/.pbz-chaos-reset/。

兼容性
覆盖 JavaScript/UI/Widget/LoadGame.js；与覆盖同一脚本的其他 Mod 互斥。
不需要 UE4SS。包中包含 .pak、.utoc、.ucas 三个文件。
已完成真实存档副本的离线变更检查和打包校验；游戏内操作与战斗刷新尚未实测。
